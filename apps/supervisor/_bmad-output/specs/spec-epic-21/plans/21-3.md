## Acceptance — 2026-09-28

- AC1: met. `resolve` validates before anything is queued. An invalid submit exits 2 with the problems verbatim and empty tables (`test/command-line.test.ts:436`). Placement refusals cover `TK_SUPERVISOR_DB` unset, under the store or `~/.tk-studio`, under `TK_STUDIO_ROOT`, and under a git checkout (`test/queue.test.ts:39-97`, `command-line.test.ts:515`). Each transition and its event commit in one transaction, and a failed transaction leaves neither (`queue.test.ts:201`, `:246`).
- AC2: met. Racing OS processes on one db file mint exactly one run, and every caller gets its id (`queue.test.ts:129`). Submitting twice returns the same run id (`command-line.test.ts:452`). Minting covers both `submit` and `wake`.
- AC3: met-with-deviation. A lock held by a live run or by a launched engine leaves the second run `queued`, naming the holder (`queue.test.ts:271`, `:313-357`, `:619-685`, `:827-898`; engine path end to end at `command-line.test.ts:802`, `:835`). The deviation is the deferred DW-3 (high): a worker that outlives a killed supervisor keeps editing the checkout after `recover` releases the lock. 21-6 owns the fix, with 21-5's tree kill. An operator caution is in `README.md` under `drain`.
- AC4: met. Restart recovery ends a started orphan `partial` with `orphaned: supervisor restart` and re-queues a run that never started. It covers the `verb_started` rule, nonce owners and the launch-orphan handover (`queue.test.ts:360-685`). The `run`, tick, `recover` and `drain` verbs recover end to end (`command-line.test.ts:554`, `:613`, `:776`). A run is never left `queued`: `drain` ends a refused run `blocked` (`:645`, `:723`). The Auto Run Result reports 192/0 tests passing and a clean tsc.
- unverifiable-here: killing a real supervisor or tick mid-run on the agent PC. To check it, first confirm no worker of the killed run is still running, then run `bun src/cli.ts drain`.
- unverifiable-here: the live `maintenance-conformance` run through the queue. It last passed in the first follow-up pass, not in the final one.
- Verdict: accepted
