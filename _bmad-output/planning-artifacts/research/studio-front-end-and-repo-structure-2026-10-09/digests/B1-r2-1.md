## Answers per lead

1. pixel-agents (S1). asyncapi.yaml read in full (1,198 lines, AsyncAPI 3.0.0, 52 interfaces). Schemas as listed in Findings: AgentStatus/AgentActivityStatus (active|waiting + awaitingInput), AgentToolStart/Done/ToolsClear, AgentToolPermission(+Clear), Subagent* keyed by parentToolId, AgentTeamInfo, AgentContextUsage (snapshot, tiers 200k/1M), SetGhostHeadlessAgents, HooksStatus (per provider, actual install state), HooksConsentRequest/Response (absolute install|notNow|never). Non-hook external producer: yes, documented and feasible. Any process can POST raw Claude-hook-shaped JSON to `POST http://127.0.0.1:3100/api/hooks/claude` with `Authorization: Bearer <token from ~/.pixel-agents/server.json>`; SessionStart stages, the next PreToolUse/Stop/Notification/PermissionRequest creates the agent; omit transcript_path for a hooks-only agent. Multi-server fan-out reads ~/.pixel-agents/servers/*.json. WS auth: Bearer in embedded mode, same-origin + optional `?token=` for privilege in standalone; spectators are read-only. Agents are created by launchAgent, by hook events, or by JSONL adoption. Constants: SESSION_END_GRACE_MS 2000; PERMISSION_TIMER_DELAY_MS 7000; TEXT_IDLE_DELAY_MS 5000; TOOL_DONE_DELAY_MS 300; HOOK_EVENT_BUFFER_MS 5000; EXTERNAL_ACTIVE_THRESHOLD_MS 120 000; DISMISSED_COOLDOWN_MS 180 000. Character pack licence: README credits "JIK-A-4, Metro City" (free top-down character pack on itch.io) as the basis of the 6 characters; the repo carries only an MIT LICENSE and no attribution file, so the pack's own terms must be read on itch.io before reuse (not retrieved this run).

2. munder-difflin (S2). Event log: hive/log.jsonl is append-only, consumers keep their own cursor; messages are one JSON file each written via temp-file + atomic rename and routed outbox→inbox by the Electron main process; per-agent cursor.json gives idempotency; processed messages move to inbox/.done/. Git is the audit layer with a single committer. Ticket model: tasks.json (id, assignee, spec, status, result ref) owned by the god agent; no kanban columns in these documents; SPEC.md's SQLite has agents/events/commands/layout. The FIPA-lite message envelope (act enum of seven speech acts, hops cap, requires_reply, needs_human) is the reusable piece. LimeZu: the assets are bundled in the public MIT repo under a split-licence notice (LICENSE-ASSETS + ATTRIBUTION.md), relying on the LimeZu Complete Version licence's permission for commercial use with credit; the cast sprites were deliberately drawn procedurally so they are MIT.

3. claude-office (S3). Request: POST /api/v1/events, body {event_type, session_id, timestamp?, data{...}} parsed as the AnyEvent discriminated union; 23 event types; per-session rate limit 1000/60 s; immediate 200 {"status":"accepted",...} with background processing. WebSocket state payload: not retrieved as a single schema (websocket.py exposed only origin and session-id validation in the grep); the state models that feed it are in models/sessions.py (Session, WhiteboardData, KanbanTask, HistoryEntry, ConversationEntry, BackgroundTask). `make simulate` = `uv run python scripts/simulate_events.py [basic|complex|edge_cases|quick|teams] [--session ID] [--quiet]`, scenarios are Python functions taking a SimulationContext and posting events to the live backend; no static JSON fixtures.
