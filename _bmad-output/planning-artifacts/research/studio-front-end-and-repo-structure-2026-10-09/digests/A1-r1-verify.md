## Notes

- Claim A1.1: Verified in full. Four release workflows (omnarad, cluster, sdk, cli) each keyed to its own tag prefix; tag counts 37/39/27/27 and zero bare `v` tags; `omnarad-stable` is a real rolling release (published 2026-08-05, re-pointed 2026-10-08, referenced from omnarad-release.yaml). compose.yaml puts migrate/api/worker under `profiles: ["app"]`, which is why the README's `--profile app` is needed; the README's clone and compose lines match verbatim. Nuance: the "three deployables" count excludes the CLI, which has its own `cli-` prefix and workflow with 27 tags, so it is really four tag streams.
- Claim A1.2: Verified except one number. Live `packages/` has 32 directories, not about 28 (the workspace globs also reach into `packages/console/*`, `packages/stats/*`, `packages/sdk/js`, `packages/slack`, so the workspace count differs from the directory count either way); the digest should say "about 30" or quote the glob list. Core releases are roughly weekly (eight releases 09-04..10-06, two on 09-04) and tag-driven, not cron-scheduled. `vscode-v` (13 tags, own workflow), Happy `cli-` (15 tags, `release-happy-cli.yml`) and PostHog's four schemes (190 / 2803 / 2 / 11 tags) all confirmed.
- Claim A1.3: Unverified independently. The ADR page itself confirms every sub-claim (date 2020-11-17, Accepted, rebuild-and-retest problem, "contracts" and "keep sub repos maintained" as consequences; note the page does not label them costs, that is the digest's reading). The page's "View source" link names github.com/ministryofjustice/opg-sirius-docs, which returns 404 to `gh api` (private), so the commit date could not be read; the Wayback CDX endpoint was offline for this URL; code and repository searches across the ministryofjustice org found no public copy. The page carries "last reviewed on 10 December 2024" with a lapsed review date.
