## Notes

- Claim B2.1: verified overall. Next.js 16.4.0: GitHub release (2026-10-07) and npm (2026-10-06) agree on version; the one-day gap is release-note posting lag. pixi.js 8.22.0 (2026-10-01) confirmed from npm (the original used GitHub releases); unpkg measurement 237,380 B gzip -6 / 236,838 B gzip -9 matches "about 237 KB". @pixi/react 8.0.5 (2025-12-01) and zero commits since 2026-01-04 confirmed from git data; correction of detail: #652 is an open unmerged pull request (filed 2026-08-31, no activity since), not an issue, which strengthens the point that the strict-mode destroy bug is unfixed in any release. Phaser 4.2.1 (2026-07-09) confirmed from npm; unpkg 354,518 B gzip -6 / 352,227 B gzip -9 matches "about 352 KB"; exactly 3 commits in the 90 days to 2026-10-09, last 2026-08-21. Godot 4.7.2 (2026-08-18) confirmed by Flathub and Homebrew (godot and godot-mono casks); C# web export confirmed absent from every shipped release because the implementing PR 106125 is still an open draft (milestone 4.x, updated 2026-09-14); one 2026 blog (gtstu.com) calls it "experimental" but in the same breath says it is not shipped, so no material dispute. Rive: paid-export gating and tier prices (Cadet $9/seat/mo, 3 seats; Voyager $32; Enterprise $120) confirmed by a 2026-05-03 third-party review and a comparison site; the specific effective date 2025-10-20 was reached only through rive.app's own blog, so the date stays vendor-sourced (unverified independently, not disputed). Not reached: Rive's statement that already-exported files keep working (vendor-only).
- Claim B2.2: verified. The Next.js source code (not docs) emits warnings that "rewrites", "redirects" and "headers" "will not automatically work with output: export" and fails pages lacking generateStaticParams; the SWC transform hard-errors "`ssr: false` is not allowed with `next/dynamic` in Server Components. Please move it into a Client Component." Server Actions, the default image loader and per-request handlers are confirmed unsupported by a third-party deployment write-up (Paulund, 2026-04-08). cookies() being forbidden is confirmed only at the level of third-party blog summaries (fails the static check as dynamic server usage); no source-level string was located within budget, so that single item is weakly verified. The matrix scores and the hybrid DOM + one Pixi canvas recommendation are the digest's own judgement and were not scored.
- Claim B2.3: verified. template-nextjs package.json (via jsDelivr's GitHub mirror) pins phaser 4.0.0 / next 15.3.1 / react 19.0.0 while npm phaser is 4.2.1; PhaserGame.tsx re-read confirms useLayoutEffect with a null-ref guard and destroy(true) + null in cleanup (strict mode: boot, destroy, boot again). This is a code-content claim, so the check is a re-read of the same file rather than a different publisher. Godot issue 70796: open, no milestone, updated 2026-06-19; nuance: the PR implementing it (106125) carries the "4.x" milestone, meaning unscheduled rather than targeted. PixiJS #11486: open, updated 2026-06-21, labelled env: mobile and priority: low (so not on a fix track). The "no primary integer-zoom recipe" coverage claim held up against a second official page (the v8 Application guide, which documents only `resolution` and `autoDensity`) and a web search that surfaced only forum threads.
