**Scope.** Which open-source projects and products, as of 2026-10-09, cover the ten capabilities a one-maintainer studio layer on Claude Code built for itself. Windows-first, Claude Code as harness, Max subscription pays (API-key / gateway requirements flagged), unattended runs in Docker Sandboxes microVMs, one maintainer (health and licence matter).

**Budget used.** 16 of 18 surface calls: 6 GitHub API batches (`gh api` health, READMEs, releases, licence files, in-repo docs, code search), 6 WebSearch, 4 WebFetch (2 succeeded: Langfuse coding-agent page, Factory Missions overview; 1 returned 404 on a guessed Paperclip docs URL; 1 was a 308 redirect that was then followed).

**Sources.** 9 distinct of 14 allowed: GitHub API (counted as one), six WebSearch result sets, langfuse.com, docs.factory.com. All GitHub numbers were read live on 2026-10-09; `open_issues_count` includes open PRs.

**Reading guide.** Health = stars / last push / latest releases / open issues (incl. PRs). "Subscription-compatible" = runs on a Claude Pro/Max login without an Anthropic API key or a third-party gateway. "Flag" = needs an API key, a gateway, or reuses the subscription OAuth token outside Claude Code (a terms-of-service question this digest does not resolve).
