## Constraints a from-scratch design must honour

- Windows 11 is the production host; Linux-only verification has let three Windows-only defects through (H0928 L41; LPC2 2026-09-29T00:24:26).
- The Claude desktop app is MSIX: never start daemons, first-run tools or the service from an app session (HA0927 L67-77; RUNBOOK §8).
- `claude -p` from Task Scheduler hangs without a console window-station: auto-logon plus a console-hosted service (RUNBOOK §8 row 1; EPICS L1561).
- Dense Bash can end the REPL silently after 10-30 min; transcripts get garbage-collected: resume from `.jsonl`, back up with `/E` never `/MIR` (RUNBOOK §8 rows 2, 4).
- Billing is the Max subscription only, one shared bucket; no API-key SDK path; Hermes bills elsewhere (PP0926 L26, L229-233; SBRIEF L75).
- Bypass only inside Docker Sandboxes; never on the host; the `permissions.deny` list is never routed around; `rm -rf` is denied (SBRIEF L140-154; H0928 L133).
