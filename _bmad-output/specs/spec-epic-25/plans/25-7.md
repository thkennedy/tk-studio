## Intent

Epic 25 made the installer-written skills-dir plugin the user delivery path (AD-21, O5), but the README, the offline runbook and runbook §3.4 still teach the marketplace install. This story rewrites those docs so that the bootstrap plus `tk-studio install` is the only user path, the marketplace is a developer catalog pinned to a tag, the archive-envelope record is marked historical, and the skills-dir form carries the red team's deprecation watch (rule 3). The 0.3.0 release (AC2) is the operator's release motion; the loop never runs it, so this story lands the docs and records the motion's exact commands.

- AC2. **Given** the release gate **When** the story closes **Then** the plugin ships at 0.3.0 (a minor bump: the distribution changed) through the generalised motion with the roster, `released-roster.json` and `plugin.json` in lockstep (gate ×4), the lib suite and conformance are green, and `tk activate` is clean on all four planes on TIM-PC-2 with the plugin loaded from the skills-dir folder

## Risks and open decisions

- **The release is the operator's.** The loop never tags, publishes or runs `release_archive.py` (customization l.66). The story names the 0.3.0 bump, but a gate ×3 bump without the archive-record commit fails `test_gate_files_are_in_four_way_lockstep` and leaves the suite red. Default: **do not bump** in this story. AC2 is `unverifiable-here`, with the full motion written into the offline runbook (or the Auto Run Result). **Block If** the session concludes the bump must land in the loop's commit anyway: that would commit a red gate, which is the operator's call.
- **Block If** `components.cli` is absent from `latest.json` and a doc step would depend on `cli--v0.1.0` (the 25-4 replan): record it as unverifiable and never fabricate a tag, URL or digest.
- **Block If** a doc rewrite needs a code or test change (installer, `plugin_leg.py`, a test pinning README text): this story is documentation only. The bootstrap subsection's bytes are pinned by tests, so leave it alone.
- **Offline path honesty.** Do not claim the `file://` roster route or the manual extract as proven live unless a test or the 25.2 probe shows it. Mark any untested route "not yet run on a box". The offline machine also needs the meta-CLI, whose bootstrap downloads `uv` and the wheel, so say so.
- **Never edit** `SPEC.md`, `epics.md`, the 25.6 kb section or the 25.6 runbook text beyond stale marketplace references, and never run `sbx` or any marketplace command from this session.
- Writing "deprecation watch: none found as of <date>" is fine; never invent a deprecation notice.
