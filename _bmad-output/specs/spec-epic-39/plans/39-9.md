## Intent

Epic 39 is a records epic only at its end. This story runs last, after 39.1 to 39.8 have landed. It completes each of the epic's records from what actually landed: the code on HEAD, the stories' specs (Auto Run Result, `DRIFT:` lines, Stage Log), the merged PRs and the handoff's landing updates. The plans' Settled shapes are not a source here.

It writes one new record, `kb/studio-front-end-epic-39.md`. That record includes the phone section's evidence, which comes from a pure layout model and a vitest that reports where each text screen breaks at 375 px and 390 px. No layout changes.

It decides nothing that is the owner's (CAP-26, CAP-27; addendum §4 choice 5; D5). The 38.7 precedent applies: a cited docs pass, annotate and never delete, and one list of what stays the owner's.

     - A text part is the longest unbreakable token the screen renders from a real record, a named literal with its `why`: `TKSTUDIO-233`, `ST-182`, a run id `q-run-epic-39-20261109T171223Z-d1df17`, a label constant. The toy fixtures are not used for this.
