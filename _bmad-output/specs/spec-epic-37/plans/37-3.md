## Intent

Story 36.3's first dev attempt hit the engine's 90-minute clock with its work uncommitted: with `[scm] rollback_on_failure = false` the engine paused for a manual `git reset`, discarded the armed graceful stop (`stop-request-discarded`), the close-out opened a draft PR with no host leg for the two stories already landed, the attempt left no Stage Log row and the cancelled run's `job-run` line carries no worker cost (holes 105, 106; the retrospective's C3, C6; DW-148). This story makes a clock a pause with a bounded exit: the pin's run-worktree policy turns the engine's own rollback on (never on a main checkout), the pending stop survives, the pause close-out runs the leg on the landed commits and opens the PR ready on green, the planner's guidance splits a story the clock threatens, a timed-out attempt gets its Stage Log row, a cancelled run's line carries its cost, a run carrying `own_block` is not counted toward `max_runs` (DW-157) and a figure-1 run whose arming was refused ends at the boundary instead of relaunching (DW-161).

## Acceptance Criteria

AC1. **Given** a run's own worktree (never a main checkout) and `[scm] rollback_on_failure` **When** a dev session ends `timeout` with uncommitted work **Then** the policy the pin writes for a run worktree sets `rollback_on_failure = true` (the attempt's tracked changes reverted, only the files this run created removed, the studio-managed base patch documented in `kb/bmad-base-patches.md`) so the engine retries or escalates without a hand reset; the pending graceful stop survives the pause (`stop-request-discarded` never follows a timeout); the pause close-out runs the host leg for the commits already landed and opens the PR ready on green, not a draft with no leg (DW-148)

AC2. **Given** a band-L story whose plan's Files list or estimated passes exceed the dev clock (`session_timeout_min`), and the stage log of a timed-out attempt **When** the planner plans it, and when the attempt ends **Then** the planner splits it (two plans, the second a follow-on story in `stories.yaml`) or names the halt consult's split candidates in the plan's risk; the timed-out attempt writes its Stage Log row (`outcome: timeout`, its tokens and cost from the session record); the retrospective's rollup counts it

AC3. **Given** a cancelled run, a run ending on the supervisor's own block (`own_block`), and a figure-1 run whose stop arming was refused **When** the queue ends it **Then** the `job-run` ledger line carries the worker's cost (the `accounted` event's figure) for a cancelled run (C6), a run carrying `own_block` is not counted toward `stop.max_runs` in `evaluate_stop` (DW-157), and a figure-1 run whose arming was refused never relaunches at close-out: it ends the run at the boundary with a line (DW-161); the supervisor suites and `test_jobrun` cover each; the contract names the rules (0.1.32, additive)

## Risks and open decisions

- **oversize, over the clock itself**: ~18 files, ~500-550 lines (source ~160: worktree 55, closeout 35, cli 10, jobrun 3, plansync 35; docs and contract ~40; tests ~350). Halt (`halt` consult) if the Files list grows past the band — the dev session never splits the story. Split candidates if the clock threatens: (i) the policy write and the DW-148 leg; (ii) the Stage Log backfill and the planner rule; (iii) C6, DW-157, DW-161.
- Block If the engine's rollback semantics must be narrowed to "only the files this run created removed" beyond the engine's own rule (untracked files since the attempt's baseline; `.bmad-loop` and the BMAD artifact folders kept; tracked `_bmad-output` edits reverted; the attempt parked on `attempt-preserve*` refs visible from the main checkout): no design document constrains a studio-side filter — consult (`bad_spec`); the design note states the engine's rule.
- Block If a tracked story spec is reverted by the reset so the timed-out row is lost even with the backfill: consult (`bad_spec`); the backfill at the next pass is the design; never a hand edit of the spec.
- Block If the paused leg must judge a dirty tree (the AC's "the commits already landed"): the design note skips it (`paused: dirty tree`); consult (`deviation-gt-0`) before any stash or WIP commit on a story run.
- Block If the cancel line's cost must be the worker's `accounted` figure alone where the PR body reads the metered engine figure (PR #302's $27.37): the design note takes `launchedCloseOutInput.costUsd` so line and body agree; consult (`bad_spec`) if the two must differ.
- Not a Block If: raising `session_timeout_min` (the retrospective's C3 alternative) is a non-goal; runs materialised before this story keep `false` (no upgrade of old worktrees).
- Not a Block If: `isRunEpic` is replaced by 37.4's `runsStories`; this story keeps the predicate call in one place so 37.4 changes one line.
- `bun` is absent on the launch host: the supervisor suites run in the engine sandbox; record the exact commands as `unverifiable-here` if the sandbox cannot run them.
