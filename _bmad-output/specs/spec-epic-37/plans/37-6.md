## Intent

Four callers build the engine's stop two ways (`runners.ts stopEngineAt` by exit code, `cli.ts launchStopGraceful`'s own host branch by JSON `ok`), the command text is rendered twice (`gracefulStopCommand`, and `rearmFailedLine` without `--directory`, DW-162), and `armStop`/`rearmStop` repeat the same block line for line (the retrospective's A2). The cycle test counts static value edges only, so `enginemcp.ts`'s `await import("./api")` is a residual it cannot see (A1, DW-164's neighbour), `withMcpStop`'s injection of `stopEngineMcp` is unpinned (DW-164), the submit-time store test's skip is silent in the host leg (B8), and the re-run verb's exit on an inconclusive leg is stated nowhere (DW-133). This story gives the stop one builder routed by tier with `--directory` always present, pinned for both tiers from one table, scans dynamic imports as edges and cuts the residual, pins the injection, names the skip, and states the three exits in the contract.

## Acceptance Criteria

AC1. **Given** the four stop callers (`closeout.ts armStop`/`rearmStop`, `launchStopGraceful`, `sweep.ts stopEngineAt`) **When** any of them stops or arms an engine **Then** one builder (`engineStopArgv(root, eid, where, opts)`) produces the argv for the host (`uv run <plugin>/lib/launch.py stop --directory <root> --run-id <eid> [--graceful]`) and the sandbox (`sbx exec <sb> uv run <vm plugin>/lib/launch.py stop --directory <vm root> …`), `rearmFailedLine` prints the builder's command (DW-162), and the supervisor suites pin the argv for both tiers from one table

AC2. **Given** the cycle test (Story 36.7) and `cli.ts withMcpStop` **When** the host gate runs **Then** the cycle test scans dynamic imports (`await import(...)`) as edges, the `enginemcp → api` residual is cut or allowlisted by name with the reason, and `withMcpStop` is pinned to inject `stopEngineMcp` (DW-164); the submit-time store test's skip is reported by `verify_host.py` as a named skip line, never silent (B8)

AC3. **Given** the re-run verb's exit on an inconclusive leg (exit 1; DW-133) and the 0.1.28 note's exit list **When** the contract is read **Then** the 0.1.32 note states the three exits (0 green, 1 red or inconclusive, 2 refused) and `test_driver_contract` pins it; DW-133 and DW-135 close by this PR

## Risks and open decisions

- **oversize**: ~20 files, ~250-320 lines (source ~70, net negative in `closeout`/`cli`; supervisor tests ~120; `verify_host` and its test ~45; contract and its test ~50; ledger ~4). The code is S-sized; the pins carry the rest. Halt (`halt` consult) if the Files list grows past the band — the dev session never splits the story.
- Block If `launchStopGraceful`'s detail strings pinned at `api.test.ts:987, :990` cannot be kept once the host branch runs the builder: the design keeps the JSON refusal detail when the output parses; consult (`deviation-gt-0`) if a caller depends on the `no JSON` detail.
- Block If the two arming roots (`engineRoot(run)` vs `servedRoot`) must become one: no design document rules it; keep both and consult (`bad_spec`) only if a test needs a single root.
- Block If bun's `(skip)` line shape on the host differs from the fixture's (`test_verify_host.py:248`'s `(fail)` shape): consult (`bad_spec`); never parse a guessed shape — the line count `, S skip` stands on its own.
- Not a Block If: the residual is cut, not allowlisted (the design note); the `MSYS_NO_PATHCONV=1` prefix and placeholders belong to the text form only; the builder throws `StudioRootMissing`/`VmPathUnderivable` where the text form substitutes placeholders.
- Not a Block If: the exit list reads "red, inconclusive or skipped" (the pinned behaviour), the AC's "red or inconclusive" widened by the design note.
- 37.2's `verdicts` parser (`== <suite>:` lines, per-file only on a fail or timeout) must not pick up the skip lines: keep them per-file `== supervisor: <rel> skip: …` so the rule excludes them.
- `bun` is absent on the launch host: the supervisor suites run in the engine sandbox; record the exact commands as `unverifiable-here` if the sandbox cannot run them.
