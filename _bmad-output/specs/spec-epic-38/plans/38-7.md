### `deferred mint`, the actual behaviour (confirmed)

`plansync.mint_deferred` (:3510-3546):
1. Writes the counter first (`save_counter`).
2. Writes the ledger's marker (`_atomic_write(path, dwledger.with_marker(...))`).

`_finish_stage` (:2234) sets `ok: false` and `artifacts` = `written`. `_deferred_main` (:3709-3729) exits 2 when not `ok`.

So the AC's reading is correct as stated: `blocked`, exit 2, `written` and `artifacts` naming the counter only, the ids burned. The extra answered keys are `ids`, `next`, `error`, `ok: false`.
