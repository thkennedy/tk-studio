## Intent

The Epic 37 retrospective found named blind spots in the gate (AI-7; B9, B10, A5, C7; DW-167, DW-172, DW-173, DW-183). Both Windows-class drives skip two folders of Python that runs on the host. A nested project's verify command is a bare `bun test`. The e2e suite (`command-line.test.ts`) runs under no gate. The `_budget` guard finds bun drives by a string literal. `guards.test.ts` turns red when the box's `TK_ATLASSIAN_*` variables are set. CAP-5's per-file timeout is pinned only by argv shape. The planner is never told the 30 000 ms host figure. And `parseSkillsList` was written for a format the real `sbx skills ls` does not print. This story makes each of these an enforced, tested rule rather than a recorded gap, and the contract's 0.1.34 entry (opened by 38.1) names the e2e step and the drives' roots.
