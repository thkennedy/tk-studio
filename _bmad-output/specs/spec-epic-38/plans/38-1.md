## Intent

The host verify leg is now the epic's largest stage (22 274 s over Epic 37's seven legs). It still runs under the engine's worker guard (`run.worker_guard_s ?? guards.max_wall_clock_seconds ?? 600`), and its own green legs exceed that guard (37.5 ran 3752 s against 3600, green only under run-epic-37's 7200 interim). A second gate on the same box halves both gates' speed (hole 113, DW-174). This story:
- gives the leg a guard of its own, `guards.host_verify_seconds` (7200 on the shipped story types), read by every caller of the leg;
- makes `tools/verify_host.py` print one `== durations:` line, recorded as `suite_durations` on the `host-verify` event and in the PR body;
- reports a guard expiry with every verdict so far green as `inconclusive (guard)` (Story 35.3's shape), never red;
- makes an operator's own `verify_host.py` refuse to start beside a live leg (`--beside-leg` overrides it);
- drops `run-epic-38`'s interim and opens contract 0.1.34;
- records the retrospective's narrowed-leg question in the handoff as Tim's, with the measured durations as its evidence.

It is first because 38.2 to 38.7 each run a leg (AI-10: AI-1 before any new surface).
