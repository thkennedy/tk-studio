## Design Notes

**The recipe (plan's formula).** `zoom` is device pixels per source pixel: `zoom = max(1, floor(min(width, height) * ratio / (tile * N)))` with `N = 12` target tiles across the container's short side, `width`/`height` in CSS pixels; non-finite or non-positive inputs give 1. The stage is scaled by `zoom / ratio` under `resolution = ratio` and `autoDensity`, so one source pixel is exactly `zoom` device pixels and a 16-pixel tile is `16 * zoom` — a whole number at any ratio. Tests also assert `tile * zoom * ratio` integral for the three integer ratios (the plan's assertion) and monotonicity in ratio.

**verify_host predicate** (proven by command output, not a unit test: no test file for this script is in Files). Cases: web changed → gate runs; web unchanged → one skip line with the reason; no base or git failure → gate runs anyway, printing why, never a silent skip. `studio_web_changed() -> tuple[bool, str]`: base = `git merge-base HEAD main`, else `git merge-base HEAD origin/main`; then `git diff --name-only <base> -- apps/studio-web` (working-tree diff against base, so uncommitted edits count). Any git failure or no base → `(True, "<why>; running anyway")`. Empty diff → `(False, "apps/studio-web unchanged since <base[:12]>")`. Argv only, `cwd=ROOT`, bounded by a timeout.
