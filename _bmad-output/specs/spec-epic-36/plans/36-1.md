## Intent

The host leg's verdict is derived three times and only two of the three know `inconclusive`: `hostverify.ts legVerdict` (right), `hostverify.ts legHistory` (an inline copy) and `board.ts hostVerifyOf` / `planstatus.ts supervisorRows` (both `skipped | green | red`), so a run whose leg ended `inconclusive` (35.3: an infrastructure failure, never a rubric fail) shows green on the board and red in the Stage Log (DW-100, the retrospective's B1). This story collapses every derivation onto `legVerdict`, files an inconclusive run under `needs_you` on the board, pins the rollup's neutrality, closes the slice path's two regression gaps (a sweep driven to `closeOut` with `slice: true` on a passing playable run; the `frames` directory literal shared by `sheet` and `proofCommit`; DW-91) and opens the contract's 0.1.31 entry. It is first because every later story's board and plan rows read the verdict.

## Acceptance Criteria

AC1. **Given** an ended run whose latest `host-verify` event is inconclusive **When** `board.ts hostVerifyOf` (~:262) and `planstatus.ts supervisorRows` (~:444-454) read it **Then** both read through `hostverify.ts legVerdict` (the inline derivations at `hostverify.ts:871-872, :881` and `planstatus.ts:454` collapse to the one), the board files the run under `needs_you` with `inconclusive`, the Stage Log row and its Jira mirror (`stage-post`) read `inconclusive`, and `report.py rollup` counts it as neither green nor red

AC2. **Given** the slice path **When** the supervisor suites run **Then** one test drives the sweep to `closeOut` with `slice: true` on a passing playable run and asserts the sheet (`worktree.ts:917, :848, :445-448`), and the frame-name contract between `sheet`'s `frames` and `proofCommit` is pinned by one literal both read (DW-91)

AC3. **Given** the supervisor suites and conformance **When** they run **Then** an inconclusive leg is fed to the board, the plan status, the stage log and the sweep tests (`planstatus.test.ts` beside its green/red cases); the contract (0.1.31, additive) names the one-verdict rule; DW-100 and DW-91 close by this PR
